# Tarave Minimal

A deliberately tiny, offline-safe fallback theme bundled with the Tarave
RetroPie module. It leaves most layout choices to the frontend's default
rendering and does not require an Internet connection or large artwork.

The module installs this theme only when the directory is absent and never
overwrites user-downloaded themes or a selected ThemeSet. Larger Batocera
themes can be installed independently from Tarave's built-in browser.
